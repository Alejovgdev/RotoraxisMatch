# Icono AJT — Aviation Job Talent

Colores: azul marino #03295B · azul #0077FD · blanco #FFFFFF

## Para la app (Expo)
- icon.png — icono principal 1024×1024. Fondo azul marino hasta los bordes, sin esquinas redondeadas ni transparencias (iOS y Android las ponen solos).
- adaptive-icon.png — icono adaptativo de Android (capa delantera, fondo transparente). Fondo: #03295B.
- monochrome-icon.png — icono temático de Android 13+ (una sola tinta).
- splash-icon.png — logo para la pantalla de arranque, sobre fondo #03295B.
- favicon.png — favicon de la web (48×48).

## Para las tiendas
- play-store-icon-512.png — icono de Google Play (512×512).
- icon.png — sirve también para App Store (1024×1024).

- icon.svg, adaptive-icon.svg, monochrome-icon.svg, splash-icon.svg — originales de los PNG anteriores.
- mark-color.svg / .png — marca AJT para fondos claros.
- mark-white.svg / .png — marca AJT para fondos oscuros.
